## Quick Start

1. **Pick an app** from above
2. **Navigate to its folder:** `cd ai-blog-to-podcast-agent/` (or whichever you chose)
3. **Install dependencies:** `pip install -r requirements.txt`
4. **Add your API key** to the `.env` file or environment
5. **Run it:** `python app_name.py` or `streamlit run app_name.py`

## Need Help?

- **Missing Python?** → [Download Python 3.10+](https://python.org)
- **Need an API key?** → [Get Claude API](https://console.anthropic.com) or [OpenAI API](https://platform.openai.com)
- **App won't start?** → Read the app's README for specific troubleshooting
