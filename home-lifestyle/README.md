## Quick Start

1. **Navigate to the app folder:** `cd ai-home-renovation-agent/`
2. **Install dependencies:** `pip install -r requirements.txt`
3. **Add your API key** to the `.env` file or environment
4. **Run it:** `python app_name.py` or `streamlit run app_name.py`
