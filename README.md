## 🚀 Getting Started

### What You'll Need
- **An API Key** — Get one free from Claude, ChatGPT, or Google Gemini
- **Python** (if running locally) — Download from python.org
- **5 minutes** — Each app takes ~5 minutes to set up

### Quick Start (Pick Any App Below)

```bash
# 1. Clone this repo
git clone https://github.com/arjkul/llm-daily-drivers.git
cd llm-daily-drivers

# 2. Navigate to an app folder
cd productivity/ai-travel-agent

# 3. Install & run
pip install -r requirements.txt
streamlit run app.py
```

**That's it!** Open your browser and use the app.

## 🔧 Setup Help

### I don't have Python installed
1. Go to [python.org](https://www.python.org/downloads/)
2. Download Python 3.10+
3. Run the installer (check "Add Python to PATH")
4. Verify: Open terminal/cmd and type `python --version`

### I don't have an API key
- **Claude:** [Get free API key](https://console.anthropic.com)
- **ChatGPT:** [Get OpenAI API key](https://platform.openai.com/api-keys)
- **Google Gemini:** [Get Gemini API key](https://ai.google.dev/tutorials/setup)

### The app won't start
1. Check Python is installed: `python --version`
2. Check dependencies: `pip install -r requirements.txt`
3. Check your API key is set as an environment variable
4. Read the app's README for specific setup
