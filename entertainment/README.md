## Quick Start

1. **Pick an app** from above
2. **Navigate to its folder:** `cd ai-journalist-agent/` (or whichever you chose)
3. **Install dependencies:** `pip install -r requirements.txt`
4. **Add your API key** to the `.env` file or environment
5. **Run it:** `python app_name.py` or `streamlit run app_name.py`
